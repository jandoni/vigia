\section{Reproducibility}
\label{sec:reproducibility}

\subsection{Reproducing the results}

Every quantitative claim in this paper traces to a committed measurement file
under \texttt{eval/results/}, each produced by an evaluation script named in
the relevant section. Detection is run once and cached, and validator
configurations replay against that cache, so a reported figure depends only on
the model and the data, not on the run. Two derived quantities — the Wilson
intervals of \cref{eq:wilson} and the Page--Hinkley model of
\cref{eq:ph-far} — are computed from the measurements rather than measured,
and their derivations are given in full where they appear.

The reference implementation, the evaluation harnesses, and the measurement
files are released together, so each table and figure can be regenerated from
the same inputs. A single command runs the licence guard, the privacy guard,
the results freeze and the test suite:

\begin{verbatim}
make check
\end{verbatim}

\subsection{Reference hardware}

All figures in this document were produced on a MacBook Pro (M4 Pro,
\SI{48}{\gigabyte}) using the \textsc{reference} backend: the as-published
dynamic-shape ONNX graph on the CPU execution provider, which is
deterministic. \Cref{sec:backends} describes the faster non-deterministic
alternative and why it is never used for a reported number.

\subsection{Data acquisition}

None of the datasets used here are redistributed. Each is fetched from its
original distributor by a script under \texttt{eval/}, which records the
licence and refuses to report success if the fetched material fails the
continuity or licence conditions of \cref{sec:demo}. Acquisition routes for
material not yet obtained are recorded in \texttt{docs/DATA\_ACQUISITION.md}.
