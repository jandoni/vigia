\subsection{Runtime dependencies}

The runtime is four packages: \texttt{onnxruntime} (MIT), \texttt{numpy}
(BSD-3-Clause), \texttt{opencv-python-headless} (Apache-2.0) and
\texttt{PyYAML} (MIT). The \texttt{ultralytics} package (AGPL-3.0) is
deliberately not a runtime dependency and is confined to an isolated build
environment (\cref{sec:licensing}). The web interface is an optional extra: a
deployed edge node runs headless and never needs it.
